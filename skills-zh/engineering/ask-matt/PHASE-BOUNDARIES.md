# 阶段边界

一个 **phase**（阶段）是一次会话里的一大块工作：那次 grilling，那次实现，那次 QA。这个定义故意是模糊的：一个阶段在你觉得 *"好的，这件事到此为止"* 的那一刻结束。

**阶段边界**是两个阶段之间的空隙，也是这个决策唯一该待的地方。阶段中间没有决策可做：要么继续，要么把剩下的活拆给若干 subagent。在阶段中间做压缩，会让 agent 丢掉线索。

## 五个选项

| 选项 | 它做什么 |
| ------------ | --------------------------------------------------------------- |
| **Continue**（继续） | 留在当前会话里，完全不做上下文切换。 |
| **`/clear`** | 清空上下文窗口，从零开始。 |
| **`/handoff`** | 写一份可携带的 markdown 文件，用它给任意位置的会话起步。 |
| **Subagent** | 把任务送到它自己的上下文窗口，拿回一份报告。 |
| **`/compact`** | 压缩当前上下文，用得到的摘要给一个全新会话起步。 |

## 决策树

在边界上自上而下地走。第一个 **是** 胜出。

**1. 还能在这个会话里继续吗？** 有两种情况让答案为 **是**：下一阶段需要把本阶段当作 **primary source**（一手来源），或者你剩下的 [smart zone](https://www.aihero.dev/ai-coding-dictionary/smart-zone) 足够多（约 150k tokens），装得下下一阶段。grilling → 实现 是标准的 **是**：实现要的是那段推理的原样，不是它的摘要。Continue 既不花钱也不丢东西，所以先把它排除掉再考虑别的。

**2. 这段上下文跟接下来要做的事无关吗？** 这个会话里的一切（探索、决策、死路）都可以扔掉吗？可以的话就 **`/clear`**。它是棋盘上最便宜的一步：不花时间，把整个窗口还给你。`/clear` 也不是终点：老会话仍然可以恢复。

弄错这一步的代价是单向的。清掉一段*相关*的上下文，你就丢掉了你所建之物的**为什么**，把 diff 读多少遍都换不回来。

**3. 你需要交接吗？** `/handoff` 的适用面很窄。只有当你需要下面这些时才用它：

- 换到一个**新的运行环境（harness）**（Claude → Codex），
- 换一个**新目录**或新仓库，
- 把活交给一位**同事**，
- 或者在不打断手头工作的前提下，把你在**阶段中途**发现的一个支线任务 fork 出去。

这份清单就是这个分支的全部条件。`/handoff` 换来的是**可携带性**：一份能带走的文件。没有东西要移动，你就不需要它。

**4. 这个任务能 AFK 完成吗？** 它的范围够不够窄，能在你离开键盘、不用引导的情况下跑完？够的话就交给一个 **subagent**，当前这个会话一动不动。自动化评审是标准场景：agent 读 diff 并回报，它做的时候不需要你在场。

**5. 其余情况，`/compact`。** 上下文相关，同一个运行环境，同一个目录，而你还得留在回路里：决策树就落在这里，而且经常落在这里。给它一条指令（`/compact we're going to QA this area`），让摘要保留下一阶段需要的东西。

`/compact` 是**默认选项，不是首选**。它排在最底，因为它上面那四个问题要么更便宜，要么更精确。人们从这里起步时的失败模式是：一个新会话自信满满地讲错一个决定，而那个决定正是被摘要压平的那一个。

## 一手来源与二手来源

除 **Continue** 之外的每一步，都把一个 **primary source**（一手来源）换成了一个 **secondary source**（二手来源）：以真实经过换成它的一份摘要。这笔交易永远是同一个形状：

| 来源 | 信息量 | 噪声 | 腾挪余地 |
| --------------------------------- | ----------- | ----- | ------------ |
| 一手（Continue） | 完整 | 很多 | 很小 |
| 二手（`/compact`、`/handoff`） | 有损 | 较少 | 很大 |

这就是问题 1 排在最前的原因。只有在继续留下的代价高于它省下的好处时，你才去付那份有损。

## 这些都是靠判断的取舍

这些问题都不客观：每一个里面都有品味的成分，同一个边界在两天里可以走两个方向。价值在于按**顺序**问它们，在边界上问，而不是在活干到一半时问。
