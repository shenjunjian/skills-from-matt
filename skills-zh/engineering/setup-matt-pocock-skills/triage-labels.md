# Triage Labels

这些 skill 用五个标准分诊角色来表述。本文件把这些角色映射到本仓库 issue tracker（工单跟踪器）实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义 |
| -------------------------- | ------------------ | ---- |
| `needs-triage`             | `needs-triage`     | 需要维护者评估这个工单 |
| `needs-info`               | `needs-info`       | 等报告者补充更多信息 |
| `ready-for-agent`          | `ready-for-agent`  | 已完整定义，可交给 AFK agent（人可以离开、由它自主完成） |
| `ready-for-human`          | `ready-for-human`  | 需要人工实现 |
| `wontfix`                  | `wontfix`          | 不予处理 |

当 skill 提到某个角色（例如"给可由无人值守 agent 处理的工单打上分诊标签"），使用本表中对应的标签字符串。

修改"我们跟踪器中的标签"这一列，让它对上你实际使用的词汇。
