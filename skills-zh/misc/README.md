- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**：创建练习目录结构，含小节、题目、答案和讲解。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**：配置 Husky 的 pre-commit 钩子，搭配 lint-staged、Prettier、类型检查和测试。
